# Audio

- `ambient-*.wav` — looping ambience/music. Reference as `music` on a chapter or `ambient` on a scene.
- `sfx-*.wav` — one-shot effects. Reference as `sfx` on a scene.

The `.wav` files here are generated placeholders (`node scripts/gen-audio.mjs`).
Replace them with real tracks (MP3/OGG/WAV all work) whenever you like.
